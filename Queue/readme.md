# Queue 

```
1. I'm using LinkedList to create a queue because LinkedList implements the Queue interface in Java.
Since Queue is an interface, it cannot be instantiated directly, 
so we need a concrete class like LinkedList, PriorityQueue, or ArrayDeque to implement its functionalities.

```
---
### Types of Queue Data structure in java:

1. `LinkedList` → General-purpose queue.

2. `PriorityQueue` → Priority-based sorting.

3. `ArrayDeque` → Efficient FIFO processing.

4. `ConcurrentLinkedQueue` → Thread-safe for multi-threading.

5. `LinkedBlockingQueue` → Bounded blocking queue for producer-consumer models.
